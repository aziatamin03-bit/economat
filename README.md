# OBAYOLI - نظام إدارة المطاعم والمخزون 🍽️📦

نظام ويب متكامل واحترافي لتسيير المطاعم، المقاهي، سلاسل الأغذية، والمخازن. يغطي النظام دورة التوريد والاستهلاك بالكامل من فواتير الشراء والبطاقات التقنية للأطباق (Fiche technique) وصولاً إلى الجرد الفعلي، تسجيل الهدر، والتواصل المباشر مع الموردين عبر WhatsApp.

---

## 🌟 الميزات الرئيسية (Features)

1. **لوحة متابعة تفاعلية (Interactive Dashboard)**:
   - مؤشرات الأداء اللحظية (عدد المواد، المواد تحت حد الأمان، قيمة المخزون، فواتير الشهر، استهلاك الشهر).
   - تنبيهات فورية للمواد التي وصلت لحد إعادة الطلب.
   - قائمة سريعة بأحدث الفواتير المسجلة.

2. **إدارة المواد والأصناف (Materials & Catalog)**:
   - تصنيف المواد (مشروبات، سوائل، معلبات، أجبان، لحوم، خضار، إلخ).
   - تسجيل أسعار FEX وأسعار الشراء وتكلفة الوحدة.
   - دعم كامل للباركود الدولي (EAN-13, EAN-8, UPC) مع إمكانية المسح بالكاميرا.

3. **إدارة المخزون والحركات (Stock & Inventory Movements)**:
   - أرصدة المخزون اللحظية مع تتبع حركات الدخول والخروج والتسويات.
   - تنبيهات فورية عندما يكون سعر الدخول أعلى من سعر FEX المحدد.
   - إمكانية تصفير أو تعديل المخزون بدقة وتوثيق كل حركة.

4. **تسجيل الهدر والتالف (Waste & Spoilage Tracking)**:
   - تسجيل المواد التالفة مع توثيق السبب (تخزين، انتهاء صلاحية، كسر).
   - حساب القيمة المالية التراكمية للهدر وخصمها التلقائي من المخزون.

5. **صرف المواد للاستهلاك (Consumption Management)**:
   - فصل استهلاك المطبخ (Cuisine) عن البار (Bar).
   - إحصائيات مالية دقيقة لقيمة الاستهلاك لكل قسم.

6. **البطاقات التقنية للأطباق (Fiche Technique)**:
   - حساب دقيق لتكلفة الطبق بناءً على أسعار المواد الأولية الحالية.
   - إمكانية ربط أطباق بمكونات مركبة (مثل خبز Cheesena أو Pain Normal).
   - توثيق خطوات التحضير، المعدات، ومسببات الحساسية لكل وصفة.
   - احتساب هامش الربح المتوقع بناءً على سعر البيع.

7. **مبيعات الأطباق والخصم التلقائي (Dish Sales & Auto-Deduction)**:
   - تسجيل مبيعات الأطباق بالكميات والتاريخ.
   - خصم مقادير المكونات تلقائياً من رصيد المخزون وتسجيلها في حركة الاستهلاك.

8. **فواتير التوريد (Supply Invoices & VAT)**:
   - تسجيل فواتير المشتريات بالأسعار دون ضريبة (HT) مع حساب ضريبة القيمة المضافة (TVA) والإجمالي (TTC).
   - تحديث رصيد المخزون وتكلفة المواد تلقائياً فور حفظ الفاتورة.
   - إمكانية حذف أو تعديل الفاتورة مع عكس أثرها على المخزون.

9. **دليل الموردين (Suppliers Directory)**:
   - بيانات الاتصال، العناوين، أيام العمل الأسبوعية، والحسابات البنكية (RIB).
   - سجل التوريد وربط المواد والفواتير بكل مورد.

10. **الجرد الفعلي والجرد العام (Stocktaking & Reconciliation)**:
    - جرد سريع مع احتساب الفروقات التلقائية (زيادة / نقص / مطابق).
    - نظام الجرد العام ومسودات الجرد مع تسجيل اسم الموظف القائم بالجرد واعتماد التسويات.

11. **التقارير والرسوم البيانية الشهرية (Monthly Analytics & Charts)**:
    - رسوم بيانية تفاعلية بواسطة Chart.js للمواد الأكثر استهلاكاً وخروجاً وهدراً.
    - جدول مقارنة رصيد بداية الشهر، الدخول، الخروج، الهدر، ورصيد نهاية الشهر.
    - إمكانية تصفح أرشيف الشهور السابقة.

12. **التواصل عبر WhatsApp**:
    - إرسال رسائل وطلبيات مباشرة للموردين والعملاء بضغطة زر.
    - سجل للرسائل المرسلة وأرقام الهاتف المحفوظة.

13. **النسخ الاحتياطي وتعدد اللغات**:
    - تصدير واسترجاع قاعدة البيانات كاملة بصيغة JSON بنقرة واحدة.
    - دعم كامل لـ 3 لغات: العربية (الافتراضية مع دعم RTL الكامل)، الإنجليزية (English)، والفرنسية (Français).
    - دعم تصدير التقارير بصيغة PDF والطباعة.

## 🚀 التثبيت والتشغيل المحلي (Getting Started)

### المتطلبات الأساسية
- [Node.js](https://nodejs.org/) (الإصدار 18 أو أحدث)
- npm أو pnpm أو yarn

### خطوات التشغيل

1. **استنساخ المستودع (Clone the repository)**:
```bash
git clone https://github.com/YOUR_USERNAME/obayoli-restaurant-manager.git
cd obayoli-restaurant-manager
```

2. **تثبيت الحزم (Install dependencies)**:
```bash
npm install
```

3. **تشغيل بيئة التطوير (Run development server)**:
```bash
npm run dev
```
افتح المتصفح على الرابط: `http://localhost:3000`

4. **بناء المشروع للإنتاج (Build for production)**:
```bash
npm run build
```
